# ShaneThoma.com

This project is meant to function as a small portfolio website that will gain more interactivity for showing off projects as I complete more of my upcoming projects.


# main vs gh-pages

The main branch is where I show the files for others to view the source code of my site, as needed or wanted.
The gh-pages branch is the branch that my website is built through on GitHub Pages using `npm run deploy` and React.
